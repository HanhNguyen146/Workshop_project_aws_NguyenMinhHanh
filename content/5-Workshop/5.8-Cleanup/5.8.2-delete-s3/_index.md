The workshop stores datasets, processed data, and trained model artifacts in Amazon S3.

After completing the workshop, these resources can be removed if they are no longer needed.

## Step 1

Open

```
Amazon S3
```

Select the workshop bucket.

> **Figure 1**

>![Figure 1](/images/5-Workshop/5.10/delete-s3/bucket.png)

---

## Step 2

Delete:

- Raw dataset
- Processed dataset
- Model artifacts

> **Figure 2**

>![Figure 1](/images/5-Workshop/5.10/delete-s3/files.png)
>![Figure 1](/images/5-Workshop/5.10/delete-s3/files1.png)
---

Optionally delete the bucket if it is no longer required.
