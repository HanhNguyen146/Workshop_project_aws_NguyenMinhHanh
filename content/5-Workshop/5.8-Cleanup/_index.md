After completing this workshop, all AWS resources should be deleted to avoid unnecessary charges.

In this chapter, you will learn how to remove the resources created throughout the workshop, including the SageMaker Endpoint, Model, Amazon S3 objects, CloudWatch alarms, and Amazon SNS topics.

Cleaning up unused resources is a recommended AWS best practice for reducing operational costs and keeping your AWS environment organized.

## Objectives

After completing this chapter, you will be able to:

- Delete the SageMaker Endpoint
- Delete the SageMaker Model
- Remove datasets and model artifacts stored in Amazon S3
- Delete CloudWatch alarms and Amazon SNS topics
