After the inference request is completed, SageMaker returns the prediction result generated by the deployed XGBoost model.

The response may include:

- Prediction label
- Prediction probability
- Confidence score

## Example test

```python
data1 = {
    "sensors": {
        "LV ActivePower (kW)_diff_1": 0.5,
        "Wind Speed (m/s)_diff_1": 0.1,
        "Theoretical_Power_Curve (KWh)_diff_1": 0.2
    },
    "timestamp": "2026-07-15T10:00:00"
}

data2 = {
    "sensors": {
        "LV ActivePower (kW)_diff_1": 50.0,
        "Wind Speed (m/s)_diff_1": 8.0,
        "Theoretical_Power_Curve (KWh)_diff_1": 45.0
    },
    "timestamp": "2026-07-15T10:00:00"
}
```
