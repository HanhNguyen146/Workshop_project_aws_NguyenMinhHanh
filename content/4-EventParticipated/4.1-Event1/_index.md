# Reflection on “AWS Community Meetup”

### Purpose of the Event

- Learn about technologies like AWS WAF, ML NIDS, Docker and their practical applications.
- Listen to career stories from IT Helpdesk to Sysadmin, and the art of teamwork.
- Explore new trends like GraphRAG and Multiplayer games on AWS.

### List of Speakers

- Mr. Le Hoang Gia Dai
- Mr. Bao Huynh
- Mr. Tran Trung Vinh
- Mr. Nguyen Quoc Bao
- Mr. Truong Huy Phuoc
- Mr. Viet Phat

---

### Key Highlights

#### 1. AWS WAF & ML NIDS

- Overcoming WAF limitations by applying Machine Learning (LightGBM, XGBoost) to build NIDS. Connecting EC2, ALB, Kinesis for real-time monitoring.

#### 2. Docker

- The difference between VMs and Containers. Docker's "build once, run anywhere" philosophy and applications in CI/CD, Microservices.

#### 3. From IT Helpdesk to Senior Sysadmin

- Career transition journey, emphasizing automation, shifting to Cloud mindset (Pay-as-you-go), and Infrastructure as Code (Terraform).

#### 4. Multiplayer Games & Teamwork & GraphRAG

- Building games with Godot and AWS WebSockets. The art of teamwork via 4 golden rules. Building GraphRAG using Amazon Bedrock and Neptune for multi-hop reasoning.

---

### Results Achieved

- Grasp the latest technology trends in security, containers, and AI.
- Consolidate personal career development orientation.

---

### Applications to Work

- Apply Docker in personal projects for easy deployment.
- Apply the 4 golden rules in teamwork.

---

### Experience in the Event

- Experience an open networking atmosphere, listening to authentic career stories from predecessors.
