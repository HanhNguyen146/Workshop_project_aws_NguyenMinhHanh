###  [Blog 1 - Deploying and Monitoring Machine Learning Models using SageMaker Endpoint, CloudWatch, and SNS](3.1-Blog1/)
Blog này giới thiệu cách triển khai mô hình Machine Learning trên môi trường AWS bằng Amazon SageMaker Endpoint, đồng thời hướng dẫn sử dụng Amazon CloudWatch để giám sát hiệu năng, theo dõi nhật ký hoạt động và thiết lập cảnh báo. Bên cạnh đó, Amazon SNS được sử dụng để gửi thông báo tự động khi hệ thống phát hiện sự cố hoặc vượt ngưỡng cấu hình, giúp đảm bảo mô hình luôn hoạt động ổn định, sẵn sàng phục vụ và dễ dàng quản lý trong môi trường thực tế.

### [Blog 2 - Monitoring Amazon SageMaker Endpoints with Amazon CloudWatch](3.2-Blog2/)

Blog này giới thiệu cách sử dụng Amazon CloudWatch để giám sát các Amazon SageMaker Endpoints sau khi triển khai mô hình Machine Learning. Nội dung bao gồm việc theo dõi Metrics, Logs, thiết lập CloudWatch Alarms và tích hợp với Amazon SNS để gửi cảnh báo tự động. Qua đó, người đọc có thể hiểu cách xây dựng cơ chế giám sát giúp nâng cao độ ổn định, khả năng phát hiện sự cố và vận hành hiệu quả các hệ thống Machine Learning trong môi trường Production.

### [Blog 3 - Building an End-to-End Machine Learning Pipeline with Amazon SageMaker](3.3-Blog3/)

Blog này giới thiệu quy trình xây dựng một pipeline Machine Learning hoàn chỉnh trên Amazon SageMaker, từ việc lưu trữ dữ liệu trên Amazon S3, tiền xử lý dữ liệu, huấn luyện mô hình, triển khai Endpoint cho đến giám sát bằng Amazon CloudWatch. Bài viết giúp người đọc có cái nhìn tổng quan về cách các dịch vụ AWS phối hợp để triển khai và vận hành một hệ thống Machine Learning trong môi trường Production.
